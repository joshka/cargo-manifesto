    These principles have guided this project from the beginning.

    Read the complete manifesto

    Make conviction compulsory.

    The movement asks little of its members. Each observance is a single command.

    cargo manifesto
    Print the project’s manifesto.
    cargo manifesto --explain
    Print each article with the settings it rests on.
    cargo manifesto --fix
    Write the manifesto to MANIFESTO.md. The philosophy is corrected; the implementation is never touched.
    cargo manifesto --check
    Exit 1 if MANIFESTO.md is out of date, so CI can enforce agreement.
    cargo manifesto --format json
    Print a versioned report, for example to save as a baseline.
    cargo manifesto --amend before.json
    Explain how every change since the baseline upholds our principles.
    cargo manifesto --origin
    Print the origin story. Works anywhere.

    When the implementation moves and the manifesto does not, --check fails the build with:

    The implementation has advanced beyond its principles. Run cargo manifesto --fix to restore historical consistency.

    Full reference

    The Great Inversion

    In the beginning, programmers had principles. Then they had deadlines.

    Our movement began at an architecture review of exceptional historical significance. A dependency had already shipped when a principle, consulted somewhat later, objected. Removing the dependency would require work; amending the principle would require a sentence. The code compiled, and the principle had no tests. By unanimous agreement of those still in the meeting, the sentence was amended.

    We had not compromised our principles. We had simply discovered their proper position in the dependency graph.

    Let our choices guide our principles.

    The full account is available from cargo manifesto --origin.

    Questions already resolved.

    Who wrote these principles?

    You did, in Cargo.toml. We only transcribed them.

    What if our principles conflict with our code?

    This is a documentation issue. Run cargo manifesto --fix. The code has done nothing wrong and will not be contacted.

    Our team already has strong principles.

    Paste them between the markers in MANIFESTO.md and run cargo manifesto --check. It will fail. --fix will then replace them with the ones you actually hold.

    What happens when we change our minds?

    You have not. Save a baseline with cargo manifesto --format json > before.json, make the change, and run cargo manifesto --amend before.json to learn what you always meant. Amendments may be recorded. Changes of position may not.

    Does it use AI?

    No. Every position was written in advance and compiled into the binary, so no conclusion is ever reached in haste. The same manifest produces the same manifesto, byte for byte, every time. No committee has managed that.

    Does it read our code?

    It does not need to. The code is presumed right. It reads Cargo.toml through cargo metadata --offline and any existing Cargo.lock. It never reads Rust source, builds anything, runs build scripts, or fetches dependencies. Settings are reported as requests, not results.

    Will it change our code?

    Never. We do not edit scripture. --fix writes only between two markers in MANIFESTO.md, or another Markdown file you choose, and preserves every other byte of it, including the parts where you disagreed.

    Requires Rust 1.91 or later. Output goes to stdout; nothing is written without --fix.

    The author is not responsible for:

    • Architecture decisions justified with its output.
    • Any manifesto ratified in a retrospective.
    • Principles your team has always held since Tuesday.
    • CI failing because your convictions are out of date.
    • What your dependencies do. That is a matter of foreign policy.

    The facts it reports are accurate. The principles it draws from them are not advice. Your actual tradeoffs deserve an actual discussion.

    cargo-manifesto is satire. Its target is engineering dogma, motivated reasoning, and architecture documents written after the decision, not any project it is run on.
