04 / Matters arising

Questions
already resolved.

What if our principles conflict with our code?+

This is a documentation issue. Run cargo manifesto --fix to bring the official position up to date.

Does this use an LLM?+

No. Our positions are prepared in advance. Only the evidence is new. The CLI matches manifest settings against a fixed catalogue of articles.

Will it change my implementation?+

Your implementation is the source of truth. --fix updates only the managed text in your manifesto. The code requires no philosophical supervision.

What happens when we change our minds?+

Save a baseline with cargo manifesto --format json > before.json. After your change, --amend before.json explains the continuity. We have anticipated this since the beginning.
